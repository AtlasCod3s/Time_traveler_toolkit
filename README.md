# Time_traveler_toolkit


A Python script that simulates booking a time-travel trip, generates a random destination year, calculates a travel cost, and prints a custom message.

## Features
- Random year generation with `random.randint()`
- Random destination selection with `random.choice()`
- Precise cost calculations using the `decimal` module
- Custom message generation via an imported local module

## What I learned
- Importing built-in modules (`datetime`, `decimal`, `random`) with different import styles
- Writing and importing my own custom Python module
- f-string formatting (`:.2f`) for clean currency output
- Working with the `Decimal` type for accurate financial math

## Usage
\`\`\`bash
python3 time_travelers_toolkit.py
